## 1. 工作目标

在 MATLAB/Simulink R2026a 下，创建一个可运行的**单一顶层 .slx 模型**，用可切换 Variant / Reference 组织下列电驱结构，并使各结构使用同一批测试工况、相同指标脚本进行**逐案独立仿真**：

1. **常规星接三相 PMSM**：真实三相绕组与星点 + 单两电平三相桥 + 标准 FOC。
2. **开绕组三相 PMSM (OEW)**：三相绕组两端均引出 + 两个三相两电平桥 + FOC + 协调双逆变器调制；共模/零序抑制开/关对照，优先研究共直流母线，并单独研究隔离双直流母线的可行性。
3. **双三相（六相、双星）PMSM**：两组三相绕组、两个星点 + 两个三相桥 + 六相 FOC，考虑绕组空间角度及磁耦合。

核心研究问题：在可追溯且公平的供电、电流/器件、材料与控制条件下，三种架构分别在高速能力、动态性能、损耗、谐波、共模/零序问题、成本和故障容错等方面表现如何？**不能预设开绕组全面最好。**

## 4. 开绕组共模与零序抑制（重点验收）

对于两组三相桥，定义每相绕组端电压：
- ua = va1 - va2；ub = vb1 - vb2；uc = vc1 - vc2；
- 绕组零序电压 u0 = (ua + ub + uc)/3；
- 零序电流 i0 = (ia + ib + ic)/3。

**必须把以下量分别定义、测量、命名：**
- 绕组端的零序电压 u0；
- 零序环流 i0 （需要真实闭合零序通路）；
- 相对于定义明确的机壳/PE 参考点的共模电压 v_cm,chassis；
- 有对地寄生网络时的泄漏电流；
- 轴承电流与传导 EMI 仅当相应物理路径/模型存在时讨论，不得用 u0 或 v_cm 代替真实测量。

至少比较：
- **S0**：基础双逆变器 PWM，无专门共模/零序抑制；
- **S1**：双桥协调 PWM / 零矢量选择，使两端零序电压差降低；
- **S2**：S1 基础上的零序电流闭环抑制（在零序物理回路及控制可实现条件下），考虑死区及器件非理想性。

每种情况给出 u0 RMS、i0 RMS、共模电压 p-p/RMS、高频频谱、相电流 THD、转矩纹波、开关次数及损耗代理指标。报告调制范围约束和失效工况。

隔离双电源作为**单独实验**：说明电源电压预算、隔离/共地关系和路径；不存在直流导通零序环流不等于没有寄生电流或没有共模干扰。

## 5. 公平对比：必须有两个供电边界

**A. 固定整车电池包/系统母线资源（主要比较）**
- 在同一电池包电压、功率和能量预算下定义不同拓扑的供电架构；
- 说明每桥 DC-link 是共用、分配还是需要隔离变换器；计入必要额外 DC/DC 和器件资源；
- 星接与开绕组尽可能使用完全相同的三相绕组和机械参数，突出连接及调制差异；
- 双三相有不同定子结构，仅在声明“相同总铜量/额定损耗/体积”假设下进行系统对照；
- 总额定电流、半导体总面积或散热预算和电源限值必须可追溯。

**B. 固定每台逆变器的 DC-link 电压（辅助极限比较）**
- 明确多出桥臂后系统能量、电源/电容/散热成本的差异；不能视为免费电压增益；
- 明确共用完整 800V 母线时，双逆变器各自器件仍按自己的完整母线电压选耐压；“每管只承受一半电压”只有在明确采用相应分压供电时才可能成立。

**避免将双桥绕组电压利用率提高直接写成“转矩翻倍”或“所有速度都效率更高”**；实际效果依赖供电连接、调制、负载、器件与磁链/电流约束。

## 6. 工况、度量和验收

必须覆盖（可以先最小闭环，再扩展工况）：

| 工况 | 指标 |
|---|---|
| 低速稳态负载 | 速度误差、Te 脉动、相电流 RMS/THD、i0 |
| 转矩阶跃 | iq 跟踪误差、响应时间、超调、峰值电流 |
| 转速斜坡/阶跃 | 调节时间、速度超调、直流侧能量 |
| 基速跨越/弱磁 | 转矩-转速能力边界、调制裕量、id |
| 正反转及再生 | 四象限、母线过压、回馈能量 |
| 母线跌落或双桥不平衡 | 电流应力和控制鲁棒性 |
| PWM 频率/死区扫描 | 电流谐波、u0/i0、损耗变化 |
| 单桥关断/单相开路 | 故障后是否可控、降额转矩；必须给出重构算法和验证，不能单凭拓扑声称容错 |

自动汇总至少包括：速度误差 RMS、95% 调节时间、Te 纹波 p-p/RMS、相电流 RMS/THD、i0 RMS、u0 RMS、共模电压 p-p/RMS、dv/dt 代理、基速/最高速、铜耗、器件导通/开关损耗（数据充足时）、各桥功率、峰值/95% 分位电流、容错降额转矩。

FFT 使用一致的稳态采样窗、频率基准与整周期/充分接近整周期的窗长。缺少材料/铁耗/机械耗/器件数据时，不能给出“准确总效率”；可报告已包含模型项和损耗代理。对于所有数值结果必须提供仿真脚本、时间、参数版本、原始 MAT 或 CSV 来源。
